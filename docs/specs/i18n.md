# i18n — Functional Spec

## Structure

```mermaid
flowchart TB
    I18N[i18n]

    I18N --> Setup[service/i18n.ts]
    I18N --> Locales[8 SUPPORT_LOCALES]
    I18N --> Files[src/lang/*.json]
    I18N --> URL[URL-based switching]
    I18N --> Guard[Router guard syncs]

    Setup --> S1[createI18n composition mode]
    Setup --> S2[fallbackLocale = en]
    Setup --> S3[Imports all 8 JSON]

    Locales --> L1[en, ua, de, pl,<br/>fr, it, bg, ar]

    Files --> F1[Each file: same structure]
    Files --> F2[Nested keys per page/section]

    URL --> U1[/en, /ua, etc. as prefix]
    URL --> U2[No localStorage]

    Guard --> G1[router.beforeEach sets locale]
```

## Functional Description

### Setup (`src/service/i18n.ts`)

```ts
import { createI18n } from 'vue-i18n'
import en from '@/lang/en.json'
import ua from '@/lang/ua.json'
import de from '@/lang/de.json'
import pl from '@/lang/pl.json'
import fr from '@/lang/fr.json'
import it from '@/lang/it.json'
import bg from '@/lang/bg.json'
import ar from '@/lang/ar.json'

export const SUPPORT_LOCALES = ['en', 'ua', 'de', 'pl', 'fr', 'it', 'bg', 'ar']

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en, ua, de, pl, fr, it, bg, ar }
})

export default i18n
```

Регистрируется в `main.ts`:
```ts
app.use(i18n)
```

### File structure

Все 8 файлов имеют одинаковую иерархическую структуру:

```json
{
  "header": {
    "nav1": {
      "control": "Board",
      "members": "Members",
      "meetings": "Meetings"
    },
    "nav2": {
      "tariffs": "Pricing",
      "contacts": "Contacts",
      "admin": "Management"
    },
    "lang": "Language"
  },
  "footer": {
    "callback": "Request a callback",
    "phone": "Phone",
    "email": "Email",
    "working_hours": "Mon-Fri 9:00-18:00",
    "social": "Follow us",
    "text_1": "..."
  },
  "email": {
    "subject_callback": "Callback request",
    "subject_consultation": "Consultation request",
    "subject_admin": "Admin access request",
    "success": "Thank you! We will contact you soon.",
    "error": "Something went wrong. Please try again."
  },
  "index": {
    "s_1": { "title": "...", "subtitle": "...", "cta": "..." },
    "s_2": { "title": "...", "stat_1": "120+", "stat_1_label": "Organizations", ... },
    "s_3": {...},
    ...
  },
  "control": {...},
  "how": {...},
  "go": {...},
  "meeting": {...},
  "mobile_app": {...},
  "tariffs": {...},
  "admin": {...},
  "privacy_policy": {...},
  "public_offer": {...}
}
```

**Соглашение по ключам:**
- `<page>.s_N` — секция N на странице `<page>`
- `<page>.s_N.title`, `.subtitle`, `.text`, `.cta` — стандартные элементы блока
- `<page>.s_N_M` — sub-block M внутри секции N

### Usage

#### В template (Options API)

```vue
<h1>{{ $t('index.s_1.title') }}</h1>
<button>{{ $t('index.s_1.cta') }}</button>
```

#### В script (Composition API)

```ts
import { useI18n } from 'vue-i18n'
const { t, locale } = useI18n()

const headline = t('index.s_1.title')
```

#### С интерполяцией

```json
{ "greeting": "Hello, {name}!" }
```

```vue
{{ $t('greeting', { name: visitorName }) }}
```

### Language switching

Через router push (см. [routing.md](routing.md)). Шаги:
1. User кликает в Header dropdown → "Ukrainian"
2. Header вызывает `router.push('/ua' + currentPathWithoutLang)`
3. Router guard видит `:lang = 'ua'` → проверяет в `SUPPORT_LOCALES` → set `i18n.global.locale.value = 'ua'`
4. Все компоненты с `$t(...)` автоматически перерисовываются на украинском
5. Все `<router-link :to="`/${$i18n.locale}/...`">` тоже обновляются

### Fallback behavior

Если ключ отсутствует в текущем locale:
- vue-i18n использует `fallbackLocale: 'en'` → возвращает английский текст
- В dev mode warning в console
- В prod — silent fallback

### No localStorage

В отличие от webadmin / api, **сайт не хранит выбранный язык в localStorage**. Логика:
- При первом посещении → URL без lang → router redirect на `/en`
- Пользователь выбрал украинский → URL стал `/ua/...` → bookmark/refresh сохраняют выбор через URL
- При следующем визите по бookmark — открывается на выбранном языке

Это **намеренно** — URL = single source of truth.

### Adding a new language

1. Создать `src/lang/<code>.json` (копия `en.json`, перевести)
2. Добавить импорт и в `messages` в `service/i18n.ts`
3. Добавить в `SUPPORT_LOCALES`
4. Добавить в language dropdown в `Header.vue`
5. (опц.) Если RTL (например, `he`, `ar`) — настроить `<html dir="rtl">` динамически

### Adding a new translation key

1. Открыть **все 8** JSON-файлов
2. Добавить ключ в одно и то же место в каждом
3. Перевести
4. Использовать `$t('new.key')` в компоненте

**Tip**: `grep -r '"new_key":' src/lang/` — найти/убедиться что добавлено везде.

## Number / Date formatting

vue-i18n умеет форматировать per-locale, но в текущей реализации **НЕ используется**. На сайте мало числовой/датовой информации — в основном маркетинговый текст.

Если потребуется (например, формат цен в тарифах) — использовать `$n(value, format, locale)` или встроенный `Intl.NumberFormat(locale).format(value)`.

## RTL для арабского

Сейчас НЕ настроено. Арабский (`ar`) текст отображается, но layout остаётся LTR.

Чтобы исправить — добавить в `App.vue`:

```ts
import { watch } from 'vue'
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()
watch(locale, (newLang) => {
  document.documentElement.dir = newLang === 'ar' ? 'rtl' : 'ltr'
  document.documentElement.lang = newLang
}, { immediate: true })
```

И в `style.scss` — RTL-вариант для key-стилей (или использовать logical properties `padding-inline-start` вместо `padding-left`).

## Known gaps

- **`<html lang>` хардкодом** на `ua` в `index.html` → не синхронизировано с current locale
- **RTL для арабского** не настроено
- **Все 8 locale в bundle** — можно lazy-load
- **Sync between languages** — manual edit всех 8 файлов; tooling нет
- **Missing keys telemetry** — нет в prod
- **Pluralization не используется** — но есть в vue-i18n как `$tc`
